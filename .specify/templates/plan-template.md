  Tool contracts must specify input/output schema, side effects, rate limits, tenant-scoping.

  If yes: confirm no PyTorch/transformers/GPU libs. DL models via ONNX only. Image stays <500 MB.

  Every architectural choice must be backed by a measured number, not opinion.
